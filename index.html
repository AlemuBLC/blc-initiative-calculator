How to use this calculator

A five-minute walkthrough before you start entering numbers.

  1. Name your initiative at the top so it is clear what this forecast is for.
  2. Set Opportunity and Reach for the members this initiative could affect.
  3. Set Adoption % separately for Low, Medium and High. This is the only row that always varies by scenario.
  4. Choose which lever drives value: Conversion rate uplift (optimising something that already converts), Friction removed (unblocking users who drop off), or Net New Launch (no prior equivalent, full rate counts). Enter a shared baseline plus an expected uplift or decline per scenario for whichever lever you pick.
  5. Set Value per outcome and Duration to convert the outcome count into a forecast.
  6. Set Confidence and Risk using the sliders. These apply once across all three scenarios.
  7. Read the output at the bottom: three forecasts and a bar comparing them.

Before sharing a forecast, replace the stock baseline defaults with real numbers for your initiative.

How this is calculated: Reach x Adoption % = adopted users. Choose one lever: adopted users x conversion rate uplift, or adopted users x friction removed. Outcome count x Value per outcome = monthly value. Monthly value x Duration = time-adjusted forecast. Time-adjusted forecast x Confidence % x (1 - Risk %) = final forecast.
